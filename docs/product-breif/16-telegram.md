# 16. الإشعارات (Telegram)

أحداث الإشعار (2026-09-11؛ كلها `bgTasks` غير حاجبة، ولا تُرسل إلا بوجود `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` كـWorker Secrets):

- 🚨 تنبيه فوري **بالعربية** لحظة ظهور موعد — قبل إعادة التحقق، ليعمل المشغل يدويًا بالتوازي مع المعالج: الطلب، الاسم الأول، الأسبوع، الفئة `Bachelor`، رابط البوابة. KV-dedupe لكل مهمة+أسبوع (TTL ثلاثون دقيقة) حتى لا يتكرر كل tick. بلا PII حساسة (لا جوازات).
- 🤖 بدء المعالج (attempt 1/2)، 📤 إرسال النموذج (الموعد + المرحلة)، 🔁 إعادة المحاولة (التصنيف + الخطأ)، ❌ فشل نهائي للدورة (مع تنبيه صريح: المهمة تبقى `ACTIVE` وتُعاد المحاولة الـtick التالي)، ⚠️ اختفاء الموعد عند إعادة التحقق (أوقف الجهد اليدوي).
- `BOOKED`: اسم العميل، التاريخ، الوقت، مرجع الحجز، رابط اللقطة.
- `CRITICAL`: استنزاف الميزانية، تكرار فشل فوق الحد، حالة PORTAL_ERROR متكررة.

مثال نص التنبيه الفوري (يُبنى من `buildSlotAlarmMessage`):

```text
🚨 *مواعيد متاحة — قدّم الآن (البوت يحجز بالتوازي)*

الطلب: `job_1` — العميل: `Ahmed`
الأسبوع: `9/21/2026 12:00:00 AM`
الفئة: `Bachelor`
البوابة: https://appointment.bmeia.gv.at (مكتب KAIRO)

افتح الموقع وقدّم يدويًا — البوت يعمل بالتوازي أيضًا.
```
