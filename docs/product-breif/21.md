# 21. جاهزية بدء السبرنتات

**موجود فعلًا:** هذا الـbrief وحده (لا PRD ولا Architecture ولا Epics ولا UX ولا كود)، والقرارات D1–D8، ودروس الإنتاج العامة من AGENTS.md (العدالة، الاختبارات التمييزية، عدم تكرار المنطق الخالص، إدارة الأسرار).

**غير موجود ومطلوب قبل السبرنتات (بالترتيب):**

1. مواصفات البوابة (G0) — منجزة جزئيًا (`docs/portal-automation-spec.md`)؛ يتبقى التقاط أول موعد وقرار المشغل القانوني.
2. PRD + UX + Architecture (أدوات bmad: `bmad-prd`, `bmad-ux`, `bmad-architecture`).
3. قائمة Epics/Stories (`bmad-create-epics-and-stories`).
4. فحص جاهزية التنفيذ (`bmad-check-implementation-readiness`) قبل أول قصة تنفيذ.

لا توجد مستندات مكررة أو متعارضة اكتُشفت أثناء المسح — لا شيء يحتاج حلًا قبل المتابعة.
