# 11. قواعد المواعيد (Rules)

القواعد **عالمية وموحّدة لكل العملاء** (قرار المشغل 2026-08-20 — لا تخصيص لكل عميل):

```text
appointment_type = Student
window: كل يوم 07:00 - 18:00 بتوقيت القاهرة (يشمل الجمعة)
horizon: الأسبوع الحالي + 7 أسابيع أمامية (ثابت عام)
calendar_id: Bachelor = 44281520 / Master_PhD = 44279679 (حقل العميل الوحيد الخاص بالقواعد)
```

- النظام **لا يحجز** أي موعد خارج النافذة العالمية، ولا يفحص خارج الأفق المتداول.
- لا توجد تواريخ نطاق ولا أيام ولا ساعات لكل عميل في الـUI أو التخزين — الطلب يبقى نشطًا حتى `BOOKED` أو الإلغاء (D8).
- المطابقة دالة نقية بدون آثار جانبية → تُختبَر كاختبار وحدة مباشرة على المصدر الحقيقي، بلا نسخة مكررة في ملفات الاختبار (درس إنتاجي).
