# 6. مسار الحجز (Booking Path) — منفّذ ومكتمل

- **تسليم النموذج المباشر (Direct HTTP POST)**: المحرك (`executeDirectHttpBooking`) يرسل حمولة الخطوة الثالثة التي تتضمن بيانات العميل الـ18 مصفوفة (`buildStep3DetailsPayload`) مباشرة إلى `POST /HomeWeb/Scheduler` بمتوسط زمن ~200ms مع كوكيز الجلسة المسبقة ويتحقق من مرجع الحجز الرقمي `GESX-...`.
- **التشغيل الاحتياطي التلقائي (Playwright Browser Fallback)**: في حال وجود أي عائق أو متطلبات تفاعل في متصفح العميل، ينتقل المحرك فورًا وبشكل تلقائي لـ `executePlaywrightFallback` لتعبئة حقول الـDOM وإرسال النموذج تلقائيًا.
- **تأكيد الحجز واستخراج المرجع**: يتم استخراج مرجع الحجز الفعلي (`GESX-...`) من استجابة التأكيد وتسجيله فورًا مع إغلاق قفل الـDurable Object وإرسال إشعار تلغرام.
