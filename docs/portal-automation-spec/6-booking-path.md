# 6. مسار الحجز (Booking Path) — Browser Wizard عبر puppeteer (revised 2026-09-11؛ كان Playwright حتى 2026-09-10)

- **المسار الوحيد الحقيقي (Browser Wizard عبر `@cloudflare/puppeteer` — مُحدَّث 2026-09-24 بالمسار السريع Fast-Path)**: 
  1. **حقن كوكيز الجلسة مسبقًا (`setCookie`)**: يتم حقن `AspxAutoDetectCookieSupport=1` وكوكيز `ASP.NET_SessionId` قبل أي تصفح لمنع تحويلات 302 الدائرية التي تسببت في تجاوز مهلة الـ15 ثانية أثناء ذروة إصدار المواعيد.
  2. **الانتقال السريع المباشر (Fast-Path Direct POST)**: إرسال نموذج POST مباشر إلى `/HomeWeb/Scheduler` ببيانات المكتب (`KAIRO`)، المعرف القانوني (`CalendarId`)، عدد الأفراد (`PersonCount=1`)، وأسبوع الاثنين المستهدف، مما يتجاوز الخطوات 1–4 ويصل لشبكة المواعيد في **~1.2 ثانية** مباشرة (مع احتفاظ المسار التراجعي بالمعالج التقليدي في حال فشل الـPOST).
  3. **اختيار الموعد الذري داخل المتصفح (Atomic DOM Slot Selection)**: فحص واختيار زر الراديو المطابق للأسبوع المستهدف داخل سياق المتصفح عبر استدعاء CDP واحد (`page.evaluate`) بدلاً من فحص كل زر راديو عبر استدعاءات متسلسلة على شبكة الـWebSocket.
  4. **تعبئة البيانات دفعة واحدة (Batch Form Fill) مع إطلاق أحداث `blur`**: ملء 17 حقل بيانات شخصية وحقل موافقة الـGDPR دفعة واحدة مع تفعيل أحداث `focus` و`input` و`change` و`blur` لضمان استجابة نصوص التحقق التابعة لـASP.NET.
  5. **حل الكابتشا صوتيًا أولاً مع سقف مهلة (`AbortController`)**: جلب تحدي الصوت `get=sound` مع مهلة 6 ثوانٍ لمنع تعليق الجلسة، ثم حله عبر `Whisper` (مع احتياط الصورة Tesseract/Vision).
  6. **الإرسال واستخراج المرجع**: الضغط على `input#nextButton` واستخراج مرجع الحجز `GESX-...`. النجاح يسجل فورًا ويغلق قفل الـDO (`/seal`).
- **الاكتشاف يبقى HTTP**: الفحص عبر `POST /HomeWeb/Scheduler` مع `Monday` (8-weeks rolling) — العقد الموثق الوحيد (G0 §5) مع مهلة شبكة `AbortSignal.timeout(10000)` ومرونة استرجاع كوكيز الجلسة.
- **تأكيد الحجز واستخراج المرجع**: يتم استخراج مرجع الحجز الفعلي (`GESX-...` عبر `parseBookingConfirmationReference`) من محتوى الصفحة النهائية وتسجيله فورًا مع إغلاق قفل الـDO (`/seal`) وإرسال إشعار تلغرام. الفشل يعاد فحص الشبكة ويعاد المحاولة مرة واحدة فقط بنفس الدورة، ثم `ACTIVE` **دون backoff** (never-park — المحاولة التالية من أول tick تالٍ ما دامت المواعيد ظاهرة). عند اكتشاف موعد يُرسل تنبيه تلغرام عربي فوري للمشغل (الأسبوع + رابط البوابة) للتقديم اليدوي بالتوازي أثناء عمل المعالج، ثم تنبيه لكل خطوة (بدء/إرسال/إعادة/فشل/اختفاء).
